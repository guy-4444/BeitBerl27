# תרגיל: חישוב שכר נטו

## מטרת התרגיל
כתבו תוכנית המקבלת **שכר ברוטו חודשי** ומחשבת את **שכר הנטו** לאחר ניכוי התשלומים הרלוונטיים:

- הפרשות לפנסיה
- דמי ביטוח לאומי
- דמי ביטוח בריאות
- הפרשות לקרן השתלמות
- מס הכנסה

על התוכנית להציג את שכר הנטו המחושב.

## הנחיות לביצוע
1. יש לבדוק באתר [כל זכות](https://www.kolzchut.org.il/) את שיעורי הניכויים הרלוונטיים.
2. יש להתחשב במדרגות מס, בתקרות, בספים ובהגבלות החלות על כל ניכוי, לפי העניין.
3. אין להשתמש בלולאות.
4. אין להשתמש בתנאים (`if`, `else` או מקבילותיהם).
5. מותר להשתמש בפונקציות `min` ו־`max`, כפי שנלמד בכיתה.
6. **אין להשתמש בכלי בינה מלאכותית (AI) לצורך ביצוע התרגיל.**

בהצלחה!
