# תרגיל בית 3 – מערכת לניהול חשבונות בנק ב־Java

## מטרת התרגיל

מימוש מערכת בסיסית לניהול חשבונות בנק באמצעות מחלקות ואובייקטים.

בתרגיל תתרגלו:
- מחלקות, אובייקטים ובנאים (Constructors).
- משתני מופע לעומת משתנים סטטיים (`static`).
- פונקציות רגילות ופונקציות סטטיות.
- הרשאות גישה `private` ו־`public`.
- שימוש ב־Getters ו־Setters ושמירה על תקינות הנתונים.
- העברת אובייקטים כפרמטרים לפונקציות.
- שימוש במשתנים, אופרטורים, תנאים ו־`String`.

> **מגבלות:** אין להשתמש במערכים, בלולאות, בירושה, בחריגות (`Exceptions`) או בנושאים שטרם נלמדו. אין להשתמש בכלי AI לפתרון התרגיל.

**כל חלקי התרגיל (א׳–ה׳) הם חובה. אין סעיפי בונוס או רשות.**

## חלק א׳ – המחלקה `BankAccount`

צרו מחלקה בשם `BankAccount` המייצגת חשבון בנק.

### 1. שדות

| שם השדה | סוג | משמעות |
| --- | --- | --- |
| `accountId` | `int` | מספר חשבון ייחודי |
| `ownerName` | `String` | שם בעל החשבון |
| `balance` | `double` | יתרת החשבון |
| `isActive` | `boolean` | האם החשבון פעיל |
| `nextId` | `static int` | מספר החשבון הבא שיוקצה |

בחרו הרשאות גישה מתאימות לשדות. חשבו אילו שדות אסור לשנות ישירות מחוץ למחלקה.

### 2. בנאים

ממשו שני בנאים:

```java
BankAccount(String ownerName)
BankAccount(String ownerName, double initialBalance)
```

דרישות:
- חשבון חדש מקבל מספר ייחודי אוטומטית. מספר החשבון הראשון הוא **1000**.
- חשבון חדש פעיל כברירת מחדל.
- הבנאי הראשון יוצר חשבון עם יתרה `0`.
- אין לאפשר יתרה התחלתית שלילית; במקרה כזה יש לאתחל את היתרה ל־`0`.

### 3. פונקציות

ממשו את הפונקציות הבאות:

| פונקציה | ערך החזרה | תיאור |
| --- | --- | --- |
| `deposit(double amount)` | `boolean` | הפקדת סכום חיובי לחשבון פעיל |
| `withdraw(double amount)` | `boolean` | משיכת סכום חיובי, עד לגובה היתרה, מחשבון פעיל |
| `transferTo(BankAccount destination, double amount)` | `boolean` | העברת כסף לחשבון אחר |
| `closeAccount()` | `boolean` | סגירת חשבון רק אם הוא פעיל ויתרתו אפס |
| `getAccountInfo()` | `String` | תיאור מספר החשבון, שם הבעלים, היתרה והמצב |

פונקציה המחזירה `boolean` תחזיר `true` אם הפעולה הצליחה ו־`false` אם נכשלה. במקרה של כישלון אין לשנות את יתרות החשבונות או את מצבם.

**כללים נוספים:**
- אין לאפשר פעולות כספיות בחשבון לא פעיל.
- אין לאפשר העברה לחשבון עצמו או ליעד שאינו קיים (`null`).
- העברה תתבצע רק אם שני החשבונות פעילים, הסכום חיובי ויש יתרה מספקת.
- אין להשתמש בהדפסה למסך כתחליף לערך ההחזרה של הפונקציה.

### 4. Getters ו־Setters

ממשו פונקציות גישה בהתאם לצורך, תוך שמירה על הכללים הבאים:
- מספר החשבון אינו ניתן לשינוי לאחר יצירתו.
- יתרה משתנה רק באמצעות הפעולות הכספיות.
- אם מאפשרים שינוי שם בעל החשבון, אין לקבל שם ריק (`""`).
- אין חובה לממש Setter לכל שדה.

## חלק ב׳ – `static`

הוסיפו למחלקת `BankAccount`:

1. שדה סטטי `totalAccounts` שסופר את כל החשבונות שנוצרו, כולל חשבונות שנסגרו.
2. פונקציה סטטית `getTotalAccounts()` המחזירה את מספר החשבונות שנוצרו.
3. פונקציה סטטית `isValidAmount(double amount)` המחזירה `true` רק עבור סכום גדול מ־`0`.
4. פונקציה סטטית `getNextAccountId()` המחזירה את מספר החשבון הבא, **בלי** ליצור חשבון או לשנות את המונה.

השתמשו ב־`isValidAmount` בתוך הפעולות הכספיות במקום לשכפל את אותה בדיקה בכל פונקציה.

## חלק ג׳ – המחלקה `Bank`

צרו מחלקה בשם `Bank` עם השדות:
- `bankName` מסוג `String`.
- `bankCode` מסוג `int`.
- `account1` ו־`account2` מסוג `BankAccount`.

ממשו:

1. בנאי המקבל שם בנק וקוד בנק.
2. `setAccounts(BankAccount a, BankAccount b)` – שמירת שני חשבונות בבנק.
3. `getTotalBalance()` – החזרת סכום היתרות של שני החשבונות.
4. `getBankInfo()` – החזרת תיאור הבנק וחשבונותיו.
5. `getBankName()` – החזרת שם הבנק.

ניתן להניח ש־`getTotalBalance()` ו־`getBankInfo()` נקראות לאחר שהוגדרו שני חשבונות תקינים.

**שאלת חשיבה:** מה ההבדל בין החזרת פרטי חשבון כ־`String` לבין החזרת אובייקט `BankAccount` עצמו? האם החזרת האובייקט בהכרח מסוכנת?

## חלק ד׳ – בדיקות במחלקת `Main`

צרו מחלקה בשם `Main` הכוללת `public static void main(String[] args)`.

בצעו את הפעולות הבאות לפי הסדר:

1. צרו שני חשבונות עם שמות ויתרות התחלתיות שונות.
2. הדפיסו את מספרי החשבונות שלהם.
3. הפקידו `500` בחשבון הראשון.
4. משכו `200` מהחשבון השני.
5. העבירו `300` מהחשבון הראשון לשני.
6. נסו למשוך סכום גבוה מהיתרה ובדקו שהיתרה לא השתנתה.
7. הדפיסו את פרטי שני החשבונות.
8. הדפיסו את מספר החשבונות שנוצרו באמצעות פונקציה סטטית.
9. הציגו את מספר החשבון הבא, צרו חשבון שלישי ובדקו את המזהה שהתקבל.
10. בדקו ניסיון להפקיד סכום שלילי וניסיון להעביר כסף לחשבון עצמו.

11. צרו אובייקט `Bank`, שייכו אליו שני חשבונות והדפיסו את פרטי הבנק ואת סכום היתרות.
