# תרגול Java – שיעור 1

**נושאי התרגול:** טיפוסים פרימיטיביים, משתנים, פעולות חשבון, `String`, קלט באמצעות `Scanner`, פלט באמצעות `System.out.print` ו־`System.out.println`, ותנאים בסיסיים (`if / else`).

## הנחיות כלליות

- לכל תרגיל יש לכתוב **פעולה נפרדת**: `f1()` לתרגיל 1, `f2()` לתרגיל 2, וכך עד `f10()` לתרגיל 10.
- בתחילת הריצה התוכנית תבקש מהמשתמש **מספר תרגיל בין 1 ל־10**, ותפעיל את הפעולה המתאימה. לבחירה יש להשתמש ב־`if / else if / else`.
- אין צורך בתפריט שחוזר על עצמו: **בכל הרצה מבצעים תרגיל אחד בלבד**, ולאחר מכן התוכנית מסתיימת.
- בחרו **טיפוס מתאים** לכל משתנה והעניקו לו שם משמעותי.
- השתמשו ב־`Scanner` לקבלת קלט מהמשתמש, והציגו פלט ברור בעזרת `System.out.print` ו־`System.out.println`.
- בדקו כל תרגיל הקולט נתונים עם **לפחות שני קלטים שונים**.
- **אסור להשתמש בכלי בינה מלאכותית (AI)**, לרבות ChatGPT, Gemini, Copilot או כל כלי דומה, לשם פתרון התרגילים, כתיבת קוד, תיקון שגיאות או ניסוח הסברים.
- **אין להשתמש** בלולאות, במערכים, בהמרת טיפוסים מפורשת (`casting`), ב־`equals()` או ב־`switch`.
- בתרגילים המשתמשים בחלוקה, ניתן להניח שהמחלק שונה מאפס, אלא אם נאמר אחרת.

### מבנה התוכנית הנדרש

דוגמה התחלתית למבנה הקובץ. **השלימו בעצמכם** את התנאים להפעלת שאר התרגילים, את הפעולות `f3()` עד `f10()` ואת הפתרונות. אין כאן פתרונות לתרגילים:

```java
import java.util.Scanner;

public class Main {
    static Scanner scanner = new Scanner(System.in);

    public static void main(String[] args) {
        System.out.print("Enter exercise number (1-10): ");
        int exercise = scanner.nextInt();

        if (exercise == 1) {
            f1();
        } else if (exercise == 2) {
            f2();
        }

        // TODO: Add conditions for exercises 3-10
        // TODO: Handle an invalid exercise number
    }

    public static void f1() {
        // TODO: Solve exercise 1
    }

    public static void f2() {
        // TODO: Solve exercise 2
    }

    // TODO: Add f3() through f10()
}
```

**שימו לב:** כל הפעולות משתמשות באותו אובייקט `scanner` שמוגדר בראש המחלקה. אין צורך ליצור אובייקט `Scanner` חדש בכל פעולה. כשצריך לקלוט מילה אחת ללא רווחים, אפשר להשתמש ב־`scanner.next()`. בתרגילים לא נדרשת קליטת משפטים שלמים.

## חלק א' – יסודות וקלט מהמשתמש

### תרגיל 1 – תעודת זהות דיגיטלית

קלטו מהמשתמש:

- שם פרטי (מילה אחת באנגלית)
- גיל בשנים
- גובה במטרים
- האות הראשונה של שם המשפחה

התוכנית תציג את הנתונים בצורה מסודרת, ובנוסף תחשב את גיל המשתמש בעוד 10 שנים.

**דוגמה לפלט:**

```text
Name: Daniel
Age: 22
Height: 1.78
Last name initial: C
Age in 10 years: 32
```

### תרגיל 2 – ממיר זמן

קלטו מספר שלם המייצג מספר שניות, והמירו אותו לשעות, דקות ושניות שנותרו.

**דוגמה:**

```text
Enter seconds: 3675

Hours: 1
Minutes: 1
Seconds: 15
```

**רמז:** השתמשו בחלוקה של מספרים שלמים ובאופרטור השארית `%`.

### תרגיל 3 – חשבון במסעדה

קלטו:

- סכום החשבון לפני טיפ
- אחוז הטיפ הרצוי
- מספר הסועדים

התוכנית תחשב ותציג את סכום הטיפ, את הסכום הכולל ואת הסכום שעל כל סועד לשלם בחלוקה שווה.

**דוגמה:**

```text
Bill: 200
Tip percentage: 15
People: 4

Tip: 30.0
Total: 230.0
Per person: 57.5
```

### תרגיל 4 – חנות מחשבים

בחנות נמכרים שלושה מוצרים. קלטו לכל מוצר את המחיר ואת כמות היחידות שנרכשו, וכן אחוז הנחה על כל הקנייה.

על התוכנית להציג:

1. מחיר כולל לפני הנחה.
2. סכום ההנחה.
3. המחיר הסופי לאחר ההנחה.

**אתגר רשות:** קלטו גם את סכום הכסף שהלקוח שילם והציגו את העודף המגיע לו. ניתן להניח ששילם מספיק.

## חלק ב' – חישובים וחשיבה

### תרגיל 5 – מחשבון מהירות נסיעה

קלטו:

- מרחק נסיעה בקילומטרים
- זמן נסיעה בדקות

על התוכנית לחשב ולהציג:

1. זמן נסיעה בשעות (כולל חלקי שעה).
2. מהירות ממוצעת בקמ"ש.
3. מרחק שהרכב היה עובר בשעה אחת באותה מהירות.

**דוגמה:**

```text
Distance: 120
Time in minutes: 90

Time in hours: 1.5
Average speed: 80.0 km/h
Distance in one hour: 80.0 km
```

**רמז:** כדי לקבל תוצאה עשרונית גם כאשר מספר הדקות הוא `int`, אפשר לחלק ב־`60.0` במקום ב־`60`.

### תרגיל 6 – חישוב ציון סופי

בקורס מסוים הציון הסופי מורכב מ:

| רכיב | משקל בציון הסופי |
| --- | ---: |
| עבודות | 20% |
| בוחן | 30% |
| מבחן סופי | 50% |

קלטו את שלושת הציונים (בין 0 ל־100), חשבו והציגו את הציון המשוקלל.

בנוסף, השתמשו ב־`if / else` כדי להציג `Pass` אם הציון הסופי הוא לפחות 60, או `Fail` אחרת.

**דוגמה:**

```text
Assignments: 90
Quiz: 80
Final exam: 70

Final grade: 77.0
Result: Pass
```

### תרגיל 7 – בדיקת מספרים

קלטו שני מספרים שלמים והציגו:

1. מי מביניהם גדול יותר, או הודעה שהם שווים.
2. האם המספר הראשון זוגי או אי־זוגי.
3. האם המספר השני מתחלק ב־5 ללא שארית.
4. האם סכום שני המספרים חיובי, שלילי או אפס.

השתמשו בתנאים (`if / else`) ובאופרטורים שנלמדו.

### תרגיל 8 – מערכת מחירי כרטיסים

בית קולנוע קובע את מחיר הכרטיס בהתאם לגיל:

| גיל | מחיר הכרטיס |
| --- | ---: |
| מתחת ל־6 | 0 ₪ |
| 6 עד 17 | 30 ₪ |
| 18 עד 64 | 45 ₪ |
| 65 ומעלה | 25 ₪ |

קלטו את גיל הלקוח והציגו את מחיר הכרטיס המתאים.

**אתגר רשות:** אם הוזן גיל שלילי, הציגו הודעת שגיאה במקום מחיר.

## חלק ג' – מחרוזות והבנת טיפוסים

### תרגיל 9 – ניתוח מילה

קלטו **מילה אחת באנגלית שאינה ריקה** והציגו:

1. מספר התווים במילה.
2. המילה באותיות גדולות.
3. המילה באותיות קטנות.
4. התו הראשון של המילה.
5. התו האחרון של המילה.

אפשר להיעזר בפעולות `length()`, `toUpperCase()`, `toLowerCase()` ו־`charAt()`, בהתאם למה שנלמד בכיתה.

**דוגמה:**

```text
Enter word: Java

Length: 4
Uppercase: JAVA
Lowercase: java
First character: J
Last character: a
```

### תרגיל 10 – ניסויים בטיפוסים ובדיוק מספרי

בפעולה `f10()` הריצו את ארבעת קטעי הקוד שלהלן (לפי הסדר). עבור **כל קטע**:

1. חזו את הפלט **לפני** הרצת התוכנית.
2. הריצו את הקוד והשוו לתחזית.
3. הסבירו במילים שלכם מדוע התקבל הפלט.

**שימו לב:** חלק משמות המשתנים חוזרים בקטעים שונים. כדי להריץ את כולם באותה פעולה, תנו למשתנים שמות שונים בכל קטע.

**קטע א' – חלוקת מספרים שלמים:**

```java
int a = 7;
int b = 2;

System.out.println(a / b);
System.out.println(a / 2.0);
```

**קטע ב' – חריגה מטווח `int`:**

```java
int num = 2147483647;

System.out.println(num);
System.out.println(num + 1);
```

**קטע ג' – ייצוג של מספרים עשרוניים:**

```java
double a = 0.1;
double b = 0.2;

System.out.println(a + b);
System.out.println(a + b == 0.3);
```

**קטע ד' – השוואת דיוק בין `float` ל־`double`:**

```java
float smallPrecision = 100000000.0f;
double highPrecision = 100000000.0;

System.out.println(smallPrecision + 1);
System.out.println(highPrecision + 1);
```

**שאלת סיכום:** מדוע חשוב להבין את גודל הטיפוס ואת דרך הייצוג שלו בזיכרון, ולא רק כיצד מכריזים על משתנה?
